# VisionGuard API Contract Alignment

## 1. Objective
Establish a single source of truth for communication between the FastAPI backend and React TypeScript frontend, eliminating schema divergence and ensuring end-to-end type safety.

---

## 2. Canonical Contracts Architecture

1. **Backend Schemas:** Defined via Pydantic in `backend/app/schemas.py` and `backend/app/contracts.py` (which mirrors `visionguard_contracts/src/visionguard_contracts/types.py`).
2. **OpenAPI Specification:** Automatically generated by FastAPI at `/openapi.json` and exported to `frontend/openapi.json`.
3. **TypeScript Generation:** Automated via `openapi-typescript` using:
   ```bash
   npm run generate:api-types --prefix frontend
   ```
   Generating `frontend/src/lib/api-types.ts`.
4. **API Client:** `frontend/src/lib/api.ts` derives all request and response types directly from `components["schemas"]` of `api-types.ts`.

---

## 3. Resolved Schema Discrepancies

| Entity / Property | Legacy Frontend Divergence | Canonical Backend Schema | Status |
|---|---|---|---|
| **Prediction Confidence** | `score: number` | `confidence: number` | **RESOLVED** |
| **Class Identifier** | `label: number` | `class_id: number` | **RESOLVED** |
| **Class Name** | `label_name?: string` | `class_name?: string` | **RESOLVED** |
| **Matched Indices** | `clean_idx`, `corrupted_idx` | `clean_index`, `corrupted_index` | **RESOLVED** |
| **Run Status** | Ad-hoc strings | `RunStatus` enum (`QUEUED`, `RUNNING`, `COMPLETED`, `PARTIAL`, `FAILED`) | **RESOLVED** |
| **Per-Image Errors** | `string[]` | `ImageError[]` (`image_id`, `corruption`, `severity`, `error_type`, `error_message`) | **RESOLVED** |
| **Condition Results** | Fragmented field names | `ConditionResult` with nested `metrics: MetricSet` | **RESOLVED** |
| **Error Handling** | Generic string exceptions | Structured `ApiError` with status code and formatted FastAPI validation details | **RESOLVED** |

## 4. Verification Tests
- **Frontend Contract Test:** `frontend/src/test/contract-alignment.test.ts` (Validates property naming, type derivation, error formatting, and URL encoding).
- **Shared Contracts Test:** `visionguard_contracts/tests/test_contracts.py` (19 test cases verifying JSON schema export, immutability, and boundary conditions).
